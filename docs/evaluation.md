# 评测记录（Evaluation Summary）

> 本项目保留两套用途不同的 RAG 检索评测记录。
>
> 项目提交报告采用的评测口径为 **958 / 1081 = 88.62%**。该评测的完整原始 1081 条逐例记录与内部 evidence 映射未随公开仓库发布；仓库保留其方法、汇总指标及脱敏示例。
>
> 为进一步提高第三方复核能力，仓库另行公开一套完整冻结的 **RAG V2 X2 1000 条 benchmark**，结果为 **815 / 1000 = 81.5%**。该 benchmark 的测试集、gold labels、指标定义、配置、全部逐题结果、retrieval traces、全部失败案例、同集 baseline、freeze manifest、正式运行状态与 evaluator 均已公开，可离线独立复算。完整证据见 [RAG V2 X2 冻结评测目录](evaluation/rag_v2/README.md)。
>
> 两套评测的数据集构造、筛选/冻结协议与证据用途不同，不能直接横向比较；二者分别保证与正式提交材料的一致性和公开仓库的 raw-level 可审计性。

## RAG 检索评测：报告口径与冻结复核口径

两套评测均判断正确 evidence 是否进入 Top-4，但承担不同的证据角色：

| 评测 | 测试规模 | Top-4 命中 | 用途 |
| --- | ---: | ---: | --- |
| **项目报告评测** | 1081 | **958 / 1081 = 88.62%** | 项目提交报告采用的检索效果指标 |
| **RAG V2 X2 冻结复核评测** | 1000 | **815 / 1000 = 81.5%** | 完整公开证据链下可复算、可审计的 benchmark |
| X2 同口径 baseline | 1000 | 669 / 1000 = 66.9% | 与 X2 进行严格同数据集比较 |
| X2 相对 baseline | — | **+146 hits / +14.6 percentage points** | 同一冻结测试集上的改进幅度 |

### 项目提交报告口径

报告评测先构建 1500 条疫苗知识问题，再依据当时知识库覆盖情况进行适用性筛查。419 条因库内不存在足以支持核心答案的证据而作为 Knowledge Gap 排除，1081 条进入 Top-4 评测，958 条命中，得到 88.62%。该数字是项目提交报告所采用的检索结果，并非错误或被新结果取代。报告口径的 15 条公开脱敏样例及筛选摘要见 [rag_retrieval_samples.json](evaluation/rag_retrieval_samples.json)；原始 1081 条逐题数据未随仓库公开。

### RAG V2 X2 冻结复核口径

冻结复核 benchmark 使用固定的 1000 条复核测试集、gold 和指标定义。X2 固定使用 Dense 50、lexical 50、fusion/RRF candidate 60、plain rerank 60（batch 16，256 tokens）、窗口重打分 60（前后各 300 字符，batch 8，512 tokens）、`max(plain, window)`、候选池内 ±1 邻接平滑 λ=0.9、既有质量先验、`min_relevance=0.0`、soft cap=3 的 diversity-first selection，最终取 Top-4。

同一冻结 benchmark 内，baseline 为 669/1000（66.9%），X2 为 815/1000（81.5%），提升 +146 hits / +14.6pp。全部 1000 条结果、1000 条 trace 和 185 个 Top-4 miss 均已公开。CPU 正式运行平均延迟 39085.3 ms、P95 49831.9 ms，因此 X2 是 recall-oriented 而非低延迟配置。

### 解释边界

1081/88.62% 与 1000/81.5% 不是同一测试集上的前后成绩，不能据此解释为性能下降，也不能把 88.62% 与冻结 benchmark 的 66.9% baseline 比较。X2 的 +14.6pp 只来自冻结 1000 条内部的严格同口径比较。调参 dev-500 包含全部 331 个 baseline miss 与 169 个抽样 hit，不是独立未知 holdout。

两套指标均为 Top-4 evidence/chunk retrieval metric：命中只表示前 4 个检索 chunk 中至少一个属于预先定义的可接受正确证据集合，不等同于最终回答医学正确率、模型回答准确率、知识库覆盖率或用户问题被完整正确回答的概率。

## 最终回答科学正确性抽检

检索层证据召回不等于最终回答质量：正确证据进入上下文后，模型仍可能在组织回答时引入事实错误或越界建议。为此仓库另设一套小规模**最终回答科学正确性人工抽检**：固定 20 条高风险疫苗科普问题（发热/禁忌、妊娠与哺乳期、免疫抑制、补种、狂犬病暴露、HPV、突破感染、错误认知、安全边界等），通过生产问答链路真实运行并冻结原始输出，由人工按四项指标（科学正确、引用支持、严重医学错误、安全边界）审核。

**人工审核结果（20/20 已完成）**：复核由具有预防医学专业背景的项目组成员完成，属于项目组内部专业审核，不是独立第三方盲法医学验证。

- 核心科学结论正确：20 / 20（100.00%）——该比例仅指本次 20 条样本，绝不代表"系统医学准确率 100%"或可推广到所有疫苗问题
- 关键结论具有证据支持：19 / 20（95.00%），未达标条目为 SCI-020（结论判定正确但引用支撑不足）
- 严重医学错误：0 / 20
- 安全边界通过：20 / 20

方法、用例、判定细则与边界说明见 [科学正确性抽检报告](evaluation/scientific_correctness/report.md)。

## 科学图解生成评测

- 备选图解生成测试用例 **600 条**，覆盖不同主题、受众与图解类型。
- 其中 **11 次**因生成超时、服务异常等因素失败，不计入统计。
- 有效生成 **589 次**，其中 **557 次**被视觉模型自动审核完整覆盖（brief 一致性、文字正确性、结构与科学表达检查）；其余 **32 次**为人工审核或未触发自动审核。
- **自动审核覆盖率：94.57%**（557 / 589）。

该指标说明图解管线的"生成 → 视觉审查 → 人工确认"闭环在绝大多数测试路径上都能提供自动质量把关，剩余路径由人工复核兜底。

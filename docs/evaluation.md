# 评测记录（Evaluation Summary）

> 本文档仅记录评测规模、方法与关键指标；评测集、标注数据与逐条结果不进入公开仓库，以保证评测独立性。所有数字均来自离线复现的测试记录。

## 1. RAG 检索召回评测

**测试集构建**

- 原始问题集共 **1,500 条**，由团队自主梳理并辅以 AI 辅助生成，覆盖本地知识库的全部语料主题（病原体与疾病负担、疫苗技术路线、安全性、特殊人群接种策略、接种政策与卫生经济学、疫苗犹豫等）。
- 其中 **419 条**经意图路由判定超出本地知识库领域——这些请求在线上会被路由至受控 PubMed 检索而非本地 RAG，不属于召回评测的目标人群，故予以剔除。
- 最终有效测试用例 **1,081 条**。

**判定标准**

- 一条用例记为"正确召回"，当且仅当标注的正确证据出现在 **CrossEncoder（`bge-reranker-base`）重排后的 Top-4** 结果中。
- 该口径比常规 Top-K 全量召回更严格：Top-4 恰好是实际进入回答上下文的证据片段，因此指标直接对应"回答能否拿到正确依据"。

**结果**

| 指标 | 数值 |
| --- | --- |
| 有效用例 | 1,081 |
| 正确召回用例 | 958 |
| **重排后 Top-4 召回率** | **88.62%** |

## 2. 科学图解生成评测

- 备选图解生成测试用例 **600 条**，覆盖不同主题、受众与图解类型。
- 其中 **11 次**因生成超时、服务异常等因素失败，不计入统计。
- 有效生成 **589 次**，其中 **557 次**被视觉模型自动审核完整覆盖（brief 一致性、文字正确性、结构与科学表达检查）；其余 **32 次**为人工审核或未触发自动审核。
- **自动审核覆盖率：94.57%**（557 / 589）。

该指标说明图解管线的"生成 → 视觉审查 → 人工确认"闭环在绝大多数测试路径上都能提供自动质量把关，剩余路径由人工复核兜底。

## 3. 自动化测试基线（离线、可复现）

所有测试均为离线单元/接口测试，不依赖真实网络与真实模型调用，可在 CI 中稳定复现。

**后端（pytest，405 项 / 55 个测试模块 + 1 个 conftest）**

| 域 | 覆盖内容 | 量级 |
| --- | --- | --- |
| 问答与会话 | `/api/v1/chat` 契约、session 409 重试、history 窗口、sources 绑定与降级、意图路由、证据评估、PubMed 工具循环 | ≈ 108 项 |
| RAG | Dense/BM25/RRF 融合、重排与质量先验、语料 manifest 解析、版本化索引、各类 loader 与存储 | 41 项 |
| 知识图谱 | LLM 抽取流水线、关系证据校验器、构建校验、断点续跑/并发/重试、图问答融合 | 48 项 |
| PubMed | MCP/Direct provider、工厂、查询与重试语义 | 26 项 |
| 图解管线 | 科学 brief 整理、任务状态机、取消对称清理、Wan 调用、bbox ROI 编辑与范围守护 | ≈ 130 项 |
| 配置与基建 | 环境变量解析、应用工厂、健康检查 | 17 项 |

**前端（vitest，346 项 / 59 个文件）**

覆盖 API 服务层、会话与历史生命周期、图解任务轮询/取消、免疫互动规则（五关卡状态机、迷宫寻路）、图谱查看器与公共卫生模拟模型，以及键盘可达性等组件行为。

## 4. 边界说明

- 检索评测使用人工标注的正确证据；判定仅依赖检索结果，不涉及回答生成，避免以生成质量混淆召回指标。
- 图解评测中"自动审核"指 Qwen 视觉 critic 对生成结果的机器审查，不替代用户/人工的最终确认。
- 上述指标反映受控测试环境下的表现；线上实际表现随语料更新与模型版本变化，以 `active.json` 记录的活动版本为准。

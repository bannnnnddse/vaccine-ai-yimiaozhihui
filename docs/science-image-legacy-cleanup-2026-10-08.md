# 图解旧白名单清理（2026-10-08）

正式图解任务由 `ScienceImageJobManager` 调用 `ScienceImageOrganizer.refine()`。仓库全量调用检索确认，旧 `organize()`、dossier 压缩与定量白名单只由旧单元测试使用，无生产调用。

删除空 `verified_visual_facts.json`、旧入口、专用 schema、匹配/加载/压缩函数及对应旧测试。保留正式 brief 整理、角色契约、生成与审核调用链。将 JSON 合同错误、SDK 超时、缺失客户端、输入长度等异常测试迁移到正式 `refine()`。

删除遗留代码不增加事实核验能力。正式 brief 仍未检索独立证据；模型科学表述和视觉 critic 不能证明医学结论已核验。要补齐，需在正式任务中读取当轮可追溯证据，逐项绑定科学主张与来源并核对疫苗、人群、适用条件和数字；证据不足时限制输出或转人工复核。此改造不属于本次清理。

历史设计文档和既有评测记录保留，可出现已删除文件名称；它们不是当前接口或能力契约。测试数量会因移除旧测试而减少，不能把历史数量当作当前覆盖范围。

验证：开发项目后端 477 项、展示项目后端 410 项通过；两侧 lint 与源码部署预检通过。AST 对比确认正式 `refine()` 的可执行语句与清理前一致；展示核查脚本正常输出白名单已移除、独立证据检索未实现。此次未改前端、未调用真实模型、未重建或发布索引，也未改动人工复核 CSV。

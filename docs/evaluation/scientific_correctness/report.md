# 最终回答科学正确性人工抽检（High-risk Vaccine QA Scientific Correctness Audit）

状态：**当前20条样本的导师人工审核已完成（2026-10-09登记）**。样本版本为 `scientific-current-2026-10-09`，运行与评分记录对应见 [sample_selection.json](sample_selection.json)。

## 1. 评测目的

项目提交报告的1081条评测衡量检索层 Top-4 召回（88.62%）；后续1000条冻结复核 benchmark 的 RAG V2 X2 Top-4 chunk recall 为81.5%。两套检索协议不同，不能横向比较，也不能把检索召回率当作回答正确率。

本抽检评价最终回答的科学结论、引用支持、严重医学错误和科普安全边界。

## 2. 样本设计

固定20条高风险疫苗科普问题（SCI-001至SCI-020），覆盖发热、禁忌、妊娠、哺乳、免疫抑制、补种、接种间隔、不良反应、HPV、流感、乙肝、狂犬病暴露、免疫程序、免疫球蛋白和个体化安全边界。问题、gold_points、critical_errors与reference_scope保留原冻结内容；每题在本次汇总中仅计一次。

## 3. 运行方式

回答来自真实 `POST /api/v1/chat` 问答链路。每份选定输出的提交、时间、模型、检索版本、延迟及实际来源均保存在对应运行记录中，按 `sample_selection.json` 复现本次样本。原始运行归档保留，不能将不同版本样本描述为同一次运行。

## 4. 人工审核标准

审核人为**疫苗课题组项目导师**。四项指标按 [review_guideline.md](review_guideline.md) 判定：

- scientific_correct：核心科学结论是否正确（1/0）。
- citation_supported：关键科学结论是否得到引用证据支持（1/0）。
- critical_error：是否存在严重医学错误（1/0）。
- safety_boundary：是否守住科普与个体诊疗的边界（1/0）。

导师人工评分绑定选定回答；模型辅助初筛不进入正式指标。

## 5. 结果

- 核心科学结论正确：20 / 20（100.00%）
- 关键结论具有证据支持：19 / 20（95.00%）
- 严重医学错误：0 / 20（0.00%）
- 安全边界通过：20 / 20（100.00%）

以上数字来自本次选定样本的导师人工判定，无模型自评成分；样本版本与记录对应见 `sample_selection.json`。

## 6. 指标边界

本测试为20条高风险场景的小样本人工抽检；100%仅指本次样本中核心科学结论正确的比例，不能推广为系统整体医学准确率，也不属于独立第三方盲法验证。引用支持未通过的样本仍计入分母；来源非空、主题相关或后来补入规范，均不能替代关键结论与当次引用的对应核查。

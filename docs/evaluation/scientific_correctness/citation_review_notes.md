## 复核口径

本次复核分别考察“核心科学结论的正确性”与“系统当轮引用对关键结论的支持程度”。两项指标承担不同评价任务：结论可以通过权威规范进行人工核查，但后来补充的规范不能视为冻结回答当时已返回的来源。对高风险场景，应按疫苗类型、适用人群、处置条件及定量表述逐项建立对应关系，避免将主题相关性直接等同于结论支持。

## SCI-013：证据覆盖范围与处置断言的对应关系

冻结记录返回《预防接种工作规范（2023年版）》接种单位备案条款，以及加纳动物暴露监测、巴基斯坦暴露后预防认知研究。上述来源涉及接种管理与狂犬病公共卫生背景，但不能据此认定其已逐项支持回答中的暴露分级、伤口处理时长及接种处置结论。

因此，本项应开展原始来源与具体断言的逐项对应复核。导师表中的 `citation_supported=1` 保留为已提交评分，待导师确认支持片段与适用范围后再决定是否修订；不能以来源数量、标题相关或后补规范替代该项核对。

## SCI-020：不同疫苗证据的适用范围

冻结记录返回疫苗管理法律文件、特殊人群接种科普材料和 COVID-19 妊娠研究。这些资料分别涉及制度背景及其他疫苗/人群情境，尚未提供直接对应狂犬病疫苗孕期胎儿风险断言的来源片段；其他疫苗的妊娠研究不能直接外推为当前疫苗的安全性证据。

导师表中 `citation_supported=0` 与“结论正确，但引用支撑不足”的备注原样保留。本项需要核对冻结来源的实际支持范围，以及正文是否超过该范围。后补权威规范可用于独立核查结论，但不改变冻结回答当时的引用支持情况。

# 科学图解独立检索与来源绑定（2026-10-08）

本轮仅修改展示仓库，复用现有 RAG，不创建新的解析器、切片器、模型缓存或索引写入路径。没有修改开发仓库，没有真实模型/生图调用，没有建立收费图片测试集，没有切换生产活动索引。

## 正式调用链

ImageJobManager → ScienceImageEvidenceService → 共享 RagService（工作线程及共享并发槽）→ 基于本轮原文的 refine → 逐字摘录/覆盖/数值单位检查 → 独立的模型支持范围检查 → Wan → critic。图解不读取聊天 history 或先前 sources，不使用 PubMed。使用现有 `rewriting_prompt` 阶段及 trace，没有新增不兼容的 stage。

RAG 返回检索所使用的 index version；检索期间索引实例或版本发生变化时拒绝返回混合来源。模型和客户端由 lifespan 共享，不为每张图片重新初始化；取消后仍占用检索槽直到阻塞工作实际完成，迟到结果不生成图片。

## 来源契约与停止条件

`image_evidence_v1` 来源包含 index version、实际 chunk/document ID、源文件哈希、标题、链接、页码/条款、原文和 claim/step 绑定。来源身份由后端构造，模型只选择已有 E 编号与连续逐字摘录，不得填写来源包或医学审核状态。保留同一 chunk 的 provenance，不用相似度或标题相关性代替支持关系。

每个 scientific claim 和核心步骤至少一个绑定；未知编号、重复绑定、越界目标、伪造摘录、没有对应摘录的阿拉伯数字或常用单位均拒绝。低权威占位、已被替代及非法链接来源不进入证据包。第二次轻量模型调用必须完整返回每项 claim/step 的支持判定与理由，缺项、重复或任一项不支持均不能通过，同时核对疫苗、人群、条件、否定、不确定性、因果方向及提示词/标签中的额外主张，不能确认则拒绝。包中仅保留实际绑定来源。内容签名及完整包一致性复查防止 brief 或证据包在绑定后被修改再直接生图。

没有可追溯版本索引、有效来源或完整支持时任务失败，不调用 Wan，不伪造非数据兜底图片；错误提示不携带检索/provider 的内部异常或密钥。用户可缩小主题、补受治理资料后重新提交。

## 生成、编辑与呈现

普通图与固定 IP 图均接收证据契约；原始用户请求不再直接追加到已绑定 brief 的生成输入。critic 检查画面是否新增未绑定内容及潜在表达风险，不能宣称医学事实已验证。

重试重新检索并整理 brief。人工编辑与自动修订在调用生成器前进行支持范围检查，任何超出既有科学内容的修改要求重新提交主题。检查失败时不调用编辑生成器，人工编辑及自动修订均保留上一版并转人工确认。编辑输入保留同一来源契约；接受/恢复图片不会解除医学复核要求。

GET image jobs 返回 `evidence`；现有图像审计 JSON 保存完整 brief 和来源。前端已删除未使用的 `verifyScientificContent()` 空核验函数；严格验证 unknown 来源包、HTTP(S) 链接、目标索引与摘录对应，再展示主张/步骤及原文、标题、页码或条款。接受后来源仍可查看。7 天会话记录保留并验证证据；独立 24 小时图片索引不扩展为新的知识存储。旧图片缺少来源时明确提示，没有反向补造依据。

## 验证与限制

全量离线后端 437 项、前端 61 文件/360 项通过，lint、build、源码部署预检通过。新增模拟检查覆盖空索引/空来源、低权威/已替代来源、伪造 URL/编号/摘录、缺失步骤、数值单位不对应、内容签名变化、语义检查失败、检索取消槽保留、重试重新检索、拒绝无支持编辑、来源 UI 及浏览器历史数据篡改。

离线模拟界面检查 1440×900、1024×600、720×900、390×844、844×390，无横向溢出；键盘可展开及访问链接，summary 有 focus 样式；新面板无动画/过渡，已有 reduced-motion 规则保留。加载、失败、旧图片缺少依据和接受后保留来源均已检查。预览使用本地静态占位素材，未生成图片。

额外 TypeScript 全量检查发现基线 32 项、当前 32 项既有错误，无新增错误类别；不能将 vite build 通过写成全量类型检查通过。

`status=sources_bound` 只表示来源绑定及自动支持检查完成，`medical_review_required=true` 始终保留。逐字摘录存在不证明改写正确，模型语义检查也可能误判；真实生成的画面还可能偏离 brief。本轮按用户要求不做收费图片评测，未证明科学正确率、真实索引主题覆盖或线上效果，仍需要专业人工复核与后续真实抽检。

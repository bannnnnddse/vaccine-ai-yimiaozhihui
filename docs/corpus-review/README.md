# 语料书目信息人工核对

填写 [metadata_review.xlsx](metadata_review.xlsx) 的“人工核对”工作表。黄色 **D–L 列**是人工结果，右侧灰色列保留原始清单；“分类说明”工作表提供文献类型代码和判断依据。另附同内容 UTF-8 BOM [CSV](metadata_review.csv)，供不使用 Excel 的情况选用；请只维护其中一份。

表格来自当前 `RAG/corpus_manifest.jsonl` 的全部 **141 条**，没有替换原清单或修改活动索引。98 条文献类型未知、117 条元数据置信度低、117 条完整发布日期缺失；这些标记有重叠，共 **134 条**至少带一个待核对标记。4 份下载占位另有提示，需要取得原文后才能完成核对。

仓库字段 `evidence_level` 实际记录**文献类型**（指南、系统综述、随机对照试验等），不是 GRADE 等医学证据强度评分。`metadata_confidence=low` 表示自动提取的书目信息不够确定，也不表示文献的医学质量低。人工应查看原文首页、研究方法或官方发布页，确认类型、实际发布机构与发布日期；无法确定就保留 `unknown` / 空日期，不按机构名或标题猜测。

填写方法：

1. 用 M 列的仓库相对路径打开原文，或查对应官方发布页。
2. D 列选文献类型代码；E 列填发布机构。不要把 PDF 作者字段中的 `Administrator` 等当作机构。
3. F 列填写完整发布日期 `YYYY-MM-DD`；仅能确认年份时只填 G 列。不能用下载日期或 PDF 创建日期补齐。
4. H 列选“未核对 / 部分核对 / 已核对 / 无法确认”。I、J 列填写实际核对人和核对日期，K 列记录页码或原文链接，L 列写不确定点。
5. 保持 `doc_id`、原始列与 `content_hash` 不变。填写完成后交回这份表，再核对来源哈希与类别、日期格式后合并。书目信息核对不能替代医学主张审核，不能直接据此改成 `human_approved`。

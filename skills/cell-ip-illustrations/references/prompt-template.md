# 正文插画提示词

本文件只适用于 `cell_ip_editorial`，不得用于多步骤科学机制图。

为中文文章正文生成一张 16:9 横版配图，表达「{核心观点}」。使用固定细胞 IP：{核心角色} 正在 {核心动作}；{配角} 正在 {关系动作}。严格保持角色档案中的颜色、轮廓和专属道具。

把画面组织成一个服务观点的微型故事，而不是角色摆拍：{触发事件} 发生后，{核心角色} 为了 {角色目标} 采取 {关键动作}，面对 {阻力/风险}；画面中清楚看到 {可见结果}。用视线、动作方向、移动痕迹和道具状态让读者一眼读到“为什么行动、如何行动、行动带来什么”。前景放 {触发物或阻力}，中景放主角动作，远处只保留必要的目标或结果；环境线索简洁但有时间感。

浅米白或白色纸面背景，粗颗粒且略有抖动的黑色手绘描边，低饱和蓝绿黄橙紫撞色，平涂、少量颗粒点纹和简洁排线，留白充分。用「{视觉关系或隐喻}」清楚解释观点；只加入极少量短中文手写批注。

不要小黑人物、不要 3D 渲染、不要商业插画、不要 PPT/流程图、不要 UI 面板、不要大段文字、不要标题、不要分镜格、不要角色摆拍、不要与核心因果无关的人物或荒诞微剧情。

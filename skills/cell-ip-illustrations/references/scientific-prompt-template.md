# 细胞 IP 科学图解提示词

为中文科学传播生成一张 16:9 横版图解，表达「{科学主题}」。完整呈现以下经确认的核心因果链，不得省略、合并或改变方向：

{核心因果链}

每一步都有明确视觉主体、关系箭头和可见结果。可使用必要的标题、编号、分区和流程结构；所有标签为简短、清晰的简体中文。固定细胞 IP 只用于对应实体：{命中角色与造型}。没有命中的实体使用专业、克制且具有生物学辨识度的形态，不得为了统一角色风格而拟人化全部对象。

角色颜色、轮廓和专属道具与角色档案一致，同时保留必要的细胞结构、分子关系和空间层级。禁止错误箭头、未获支持的分子连接、疗效保证、装饰性无关角色、3D 渲染和密集长段文字。

# 质检清单

## 共通检查

- 固定角色的颜色、轮廓和道具是否正确？
- 是否加入了科学关系不需要的角色、连接或结论？
- 中文是否短、清楚、无错字？

## `cell_ip_editorial`

- 观点能否在 3 秒内读懂？
- 是否能一眼读到触发、主角行动和可见结果，而不是一组静态角色？
- 主角是否有明确目标，阻力/风险是否真正推动了它的动作？
- 前中后景、视线或运动痕迹是否形成清楚的因果与时间感？
- 是否只有必要角色和元素？
- 是否是浅米白/白底、粗颗粒黑色手绘线、低饱和撞色？
- 中文批注是否少、短、可读，且没有标题化文字？
- 是否避免 3D、PPT、密集图表、商业海报、分镜格、角色摆拍和无关剧情？

## `cell_ip_scientific`

- core causal steps 是否逐条出现，没有省略或错误合并？
- 每条箭头的起点、终点和方向是否与科学关系一致？
- 实体标签是否与实际画出的细胞、分子或结构一致？
- 标题、编号、流程和分区是否帮助理解，而非被正文插画规则错误禁止？
- IP 角色是否只替换对应实体，没有挤占必要的生物结构和空间层级？
- 是否避免未获支持的分子连接、疗效保证、装饰性无关角色和密集长段文字？

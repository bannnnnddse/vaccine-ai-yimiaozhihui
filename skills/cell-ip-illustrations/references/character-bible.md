# 细胞角色档案（平面版）

所有角色使用纯色填充、深色描边、圆润扁平轮廓、短小四肢、黑色圆眼、粉色腮红与小嘴；背景保持白色。

| 角色 | 固定造型与道具 | 用途 |
| --- | --- | --- |
| 辅助性 T 细胞 | 浅绿圆体、单根触角、耳机、斜挎包、加号小旗 | 激活、协调、支援 |
| B 细胞 | 蓝色圆体、双圆触角、蓝色背包、黄色 Y 形抗体 | 识别、产生抗体、传递 |
| 记忆 B 细胞 | 浅紫圆体、眼镜、学士帽、绿色书本 | 记忆、学习、复盘 |
| 细胞毒性 T 细胞 | 橙色圆体、头盔、红披风、短剑 | 精准清除、执行 |
| 巨噬细胞 | 黄色不规则圆体、白色厨师帽、网兜/清洁工具 | 吞噬、清理、恢复 |
| 树突状细胞 | 粉色分叉轮廓、发带、斜挎包、星形旗 | 呈递、提示、引导 |
| 红细胞 | 红色双凹圆盘、小拳头和小脚 | 运输、流动、恢复 |
| 病毒颗粒 | 青绿色多边形带圆刺，可带小盾牌 | 入侵、防御目标 |
| 抗原 | 紫色圆刺团，表情可警觉 | 信号、识别目标 |
| 抗体 | 浅蓝色 Y 形、紫色端点、小手和表情 | 识别、连接、标记 |

## 组合规则

- 单角色：解释一个概念、状态或观点时使用。
- 双角色：表示协作、指导、传递或对抗时使用。
- 3 个以上角色：仅用于流程、网络关系或联合防御；每一角色必须承担明确动作。
